Attributes

  1. href

    2. A href attribute is used to specify the URL of the page the link goes to.

    A href = "tel:1234567890" attribute is used to create a hyperlink to a phone number.

    A href = "mailto:example@example.com" attribute is used to create a hyperlink to an email address.

    A href = "_blank" attribute is used to open the link in a new tab.

    A href = "#section1" attribute is used to link to a specific section within the same page.

  2. id

    3. An id attribute is used to specify a unique identifier for an element.
